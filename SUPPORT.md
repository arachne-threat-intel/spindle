# Support

Are you looking for support with any aspect of Spindle?

The [README](README.md) file covers basic information about the usage of Spindle, along with information about the Vrax community.

The [CONTRIBUTING](https://github.com/arachne-threat-intel/community/blob/main/CONTRIBUTING.md) file covers the guidelines that cover all contributions to the Vrax community.

After reviewing these resources, are you still looking for support? Please email [contact@vrax.io](mailto:contact@vrax.io) to get added to the Vrax Slack, where you can communicate directly with the Arachne Digital community.
